Frequently Asked Questions

Everything about viewing AI-generated HTML & Markdown on iPhone and iPad with AI Artifact Reader.

How do I open an HTML file that ChatGPT or Claude generated on my iPhone?

Save the file (or copy the HTML text), open AI Artifact Reader, and either pick the file or use Paste HTML / Markdown. It renders instantly and fully offline. Full walkthrough: how to open HTML files on iPhone.

Can I view Claude Artifacts on my iPhone?

Yes. Copy the artifact's code (or export/download it as a file), then open it in AI Artifact Reader — it renders HTML artifacts, including dynamic, animated ones, without any internet connection. Guide: view Claude Artifacts on iPhone.

Does it work with ChatGPT canvas / code output?

Yes. Anything ChatGPT outputs as HTML or Markdown — canvas documents, code blocks, reports, dashboards — can be pasted or opened as a file. See viewing ChatGPT HTML on iPhone.

Is it really offline? What about privacy?

The app blocks the network by default — rendering happens entirely on your device and nothing is uploaded. There are no accounts, no analytics SDKs, no tracking. This is the core design: AI output often contains personal or work content, so it should never leave your phone just to be rendered.

What Markdown features are supported?

GitHub-Flavored Markdown (tables, task lists, strikethrough), fenced code blocks with syntax highlighting, Mermaid diagrams and KaTeX math. See Markdown reader for iOS.

Can it render dynamic or animated HTML, not just static pages?

Yes — JavaScript runs locally, so animated dashboards, charts and interactive single-file pages play exactly as intended, just without network access.

Can I open multi-file artifacts (HTML + CSS + JS, or a .zip)?

Yes. Pro includes a local multi-file server, so bundles where the HTML references separate CSS/JS/image files — or a .zip of them — open correctly.

How do I export an AI artifact as a long image or PDF?

Open the document, tap export, and choose full-length image (rendered at high resolution, ideal for sharing in chats and social feeds) or PDF. Export is a Pro feature.

Is the app free?

Reading, pasting and organizing are free. Pro (export image/PDF, multi-file server) is a small one-time Lifetime purchase, or a 6-month plan with a 7-day free trial. Regional pricing applies (e.g. ¥20 lifetime / ¥8 half-year in China).

Does it work on iPad?

Yes — it's a universal app for iPhone and iPad.

Can I send files from other apps?

Yes — use the iOS share sheet from Files, Safari, Mail, WeChat, etc. and choose AI Artifact Reader; the file is imported into your library.

Which AI tools does it work with?

Any tool that outputs HTML or Markdown: ChatGPT, Claude, Gemini, Grok, Copilot, Perplexity, DeepSeek, Llama, Mistral, Qwen (通义千问), Doubao (豆包), Kimi, ERNIE (文心一言) and others.
